Formularios + Inputs

Formulario 01 — Tipos de Input

Este formulario permite conocer y probar diferentes tipos de campos <input>. Incluye campos de texto, números, correo, teléfono, URL, contraseña, color, búsqueda, selección de archivos y un campo oculto.

También permite observar la diferencia entre un campo de solo lectura (readonly), un campo desactivado (disabled) y un botón de envío (submit).

Inputs

Formulario 02 — Fechas y Horas

Este formulario permite practicar los campos relacionados con fechas y hora. El usuario puede seleccionar una fecha con hora, un día específico, una hora, una semana o un mes.

Input tipo fecha

Formulario 03 — Área de Texto

Este formulario permite practicar el uso de <textarea>, un campo destinado a escribir textos de varias líneas, como descripciones, observaciones o comentarios extensos.

rows establece la cantidad inicial de filas visibles y cols establece el ancho inicial del área de texto.

Textarea

Formulario 04 — Listas de Selección

Este formulario permite comparar dos formas de utilizar <select>. La primera lista permite seleccionar una sola comida y la segunda, mediante multiple, permite seleccionar varias opciones.

Cada <option> representa una alternativa disponible dentro de la lista.

Selects

Formulario 05 — Casillas de Verificación

Este formulario permite seleccionar uno, varios o ninguno de los lenguajes. Cada checkbox funciona como una opción independiente y puede marcarse o desmarcarse sin afectar las demás opciones.

Los atributos name y value identifican el dato correspondiente a cada casilla.

Formulario 06 — Botones de Opción

Este formulario contiene dos grupos independientes de botones radio. En el grupo name="lenguaje" solamente puede seleccionarse un lenguaje. En el grupo name="comida" solamente puede seleccionarse una comida.

Como los dos grupos tienen nombres diferentes, el usuario puede seleccionar simultáneamente un lenguaje y una comida.

Formulario 07 — Validación de Datos

Este formulario permite practicar las validaciones básicas incorporadas en HTML. El nombre debe ser obligatorio y contener entre 3 y 15 caracteres. El correo debe estar completo y tener formato de email.

También es obligatorio seleccionar una comida. El formulario solo podrá enviarse cuando los campos cumplan las condiciones establecidas.
